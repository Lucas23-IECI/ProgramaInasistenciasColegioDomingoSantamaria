# Frontend - Sistema de Inasistencias LDSM

Interfaz React para el registro de entradas, atrasos e inasistencias del Liceo Domingo Santa María.

## Comandos

```powershell
npm ci
npm run dev
npm run lint
npm run build
```

La URL de la API se configura con `VITE_API_URL`. Si no se define, el entorno de desarrollo usa `http://localhost:5000/api`.
