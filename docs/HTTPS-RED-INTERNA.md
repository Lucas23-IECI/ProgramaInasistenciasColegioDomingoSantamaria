# HTTPS confiable en la red interna

Esta guía fue sustituida el 24 de septiembre de 2026 por [HTTPS del colegio, sin comprar dominio](HTTPS_COLEGIO.md).

La preparación actual utiliza certificados nativos de Windows, no mkcert. No instala hooks Git ni cambia contraseñas. Conserva la base de datos existente y genera un paquete público para configurar confianza una vez en cada PC Windows.

Consultar también [pruebas realizadas y límites](PRUEBAS_HTTPS_2026-09-24.md). No considerar verificada la instalación privilegiada en Windows o en el colegio únicamente por las simulaciones locales.
